Couverture de la base

La base regroupe les outils majeurs utilisés à l’international, des technologies d’assistance et une sélection de projets open source utiles. Elle n’est pas présentée comme exhaustive : le répertoire W3C recense lui-même plus de 100 outils et précise que sa propre liste n’est ni complète ni une recommandation de qualité.

Comment lire les évaluations

Fiabilité = confiance à accorder aux résultats dans son périmètre. Usage = fréquence d’utilisation estimée dans les équipes accessibilité / QA / produit. Les mentions Open source servent à repérer les projets dont le code peut être consulté, testé ou intégré. Aucun outil automatique ne remplace les tests manuels.

Les liens officiels sont contrôlés automatiquement par la veille GitHub Actions.
