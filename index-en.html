Master's thesis · 2026

A11y Copilot

Problem statement

How can product teams find the relevant accessibility references and turn them into understandable recommendations without presenting an LLM as a tool that can automatically declare compliance?

Approach

User research, retrieval strategy benchmarking, reranking, LLM generation, deterministic safeguards and semantic review. The scenarios address the needs of designers, developers and QA teams.

Skills used

  • RGAA
  • Python
  • RAG
  • Prompt engineering
  • LLM evaluation
  • User research
  • Product tool design

What the project demonstrates

The ability to connect standards expertise, product needs, evaluation and AI prototyping with explicit safeguards.

Collaborative project · 2026

BRA(S)VO

Connected orthosis · Sensors · BLE

Objective

Design a hand rehabilitation solution combining an instrumented orthosis, a mobile application and therapeutic mini-games for patient follow-up.

Solution

Flexion sensors, pressure sensors and an IMU transmit data over BLE. The application uses these values in the games and separates patient and therapist needs.

Skills used

  • Flutter
  • Dart
  • BLE
  • ESP32
  • Sensors
  • Mobile UX
  • Gamification
  • Git

Design challenges

Orthosis comfort, sensor calibration, connection persistence, data comprehension, motivation and home use.
